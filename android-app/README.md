# Drop and Tag for Android

Нативная Android-оболочка для `https://media.zhuamedic.kz/`.

## Что уже работает

- полноэкранный интерфейс без адресной строки браузера;
- существующая Django-авторизация и cookies;
- переходы внутри домена приложения;
- открытие внешних ссылок в подходящем Android-приложении;
- системный выбор одного или нескольких фото/видео;
- доступ к Samsung «Мои файлы» и другим Android Documents Provider;
- загрузка через существующие формы Django;
- скачивание файлов в системную папку Downloads;
- индикатор загрузки страницы;
- история по системной кнопке «Назад»;
- экран повторной попытки при отсутствии сети;
- запрет незашифрованного HTTP и отклонение ошибочных SSL-сертификатов.

Файлы по-прежнему проходят через Django на VDS и сохраняются на подключённый
Synology. Пароли SMB в APK не попадают.

## Сборка в Android Studio

1. Установите актуальную Android Studio с JDK 17.
2. Откройте каталог `android-app`.
3. Дождитесь Gradle Sync и установки Android SDK 36.
4. Подключите планшет с включённой отладкой по USB.
5. Нажмите **Run**, чтобы проверить приложение.
6. Для APK используйте **Build → Build APK(s)**.

Debug APK появится в:

```text
android-app/app/build/outputs/apk/debug/app-debug.apk
```

## Изменение адреса сервера

Адрес задаётся в `app/build.gradle`:

```groovy
buildConfigField "String", "APP_URL", "\"https://media.zhuamedic.kz/\""
```

Разрешён только HTTPS. Ссылки на другие домены открываются вне приложения.

## Release

Для распространения приложение нужно подписать собственным keystore через
**Build → Generate Signed Bundle / APK**. Файл keystore и пароли нельзя хранить
в репозитории.
